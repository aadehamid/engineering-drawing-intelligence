# DEC-080: The agent decides open questions for the owner during the MILESTONE-001b night run

Status: Decided
Date: 2026-10-19

## Context

On 2026-10-19 (UTC) the owner asked the agent to finish the retro, then pick the next
logical batch of work and drive it to closure as a night run. The agent picked
MILESTONE-001b, which the owner set as the step after MILESTONE-001
([DEC-030](DEC-030-plant-3d-backend-first.md)). [DEC-042](DEC-042-w-sp-scn-001-first.md)
limits W-SP to its SCN-001 equivalent: its SmartPlant-style backend goes through DEXPI
into the graph and must match the W-SP world file exactly. The run builds that on the
components already chosen for MILESTONE-001's slice. The agent shared the batch and its
order with the owner before starting, as the owner asked. The delegation in
[DEC-073](DEC-073-second-night-delegation.md) covered only the night run of
2026-10-14, so this run needs its own.

The owner's request to pick and drive the batch did not itself say who decides the
run's open questions, so the agent asked, and the owner answered.

How the agent applies the delegation is its own practice, as under DEC-048 and
DEC-073: it records each decision as Decided, citing this record, where the question
lives, with its evidence, and lists it in the morning log. The run stops for a
question the evidence cannot settle; for anything irreversible outside the
repository, such as spending money, publishing or deleting remote data; for rewriting
main's history; and for research that would need proprietary vendor content copied.
The owner can reverse any decision made under this record.
